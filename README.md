Curso Técnico - Arquivos HTML

Projeto com páginas de perfil pessoal e sistema de cadastro de clientes, desenvolvido com HTML, CSS e JavaScript.

Páginas
index.html

Página de perfil pessoal, desenvolvida com HTML, JavaScript e CSS.

acadastro_clientes.html

Página principal do sistema de cadastro de clientes. Consome uma API externa e direciona para as demais páginas do sistema:

listar.html — Lista todos os clientes cadastrados.
cadastrar.html — Cadastra novos clientes.
editar.html — Edita informações de clientes já existentes.
excluir.html — Exclui clientes existentes.
